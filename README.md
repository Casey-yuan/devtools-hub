## ✨ 特点 / Features

- 🚀 **纯前端实现 / Pure Frontend** - 所有数据处理在浏览器本地完成，无需上传服务器<br>
  All data processing is done locally in the browser, no server upload required
  
- 🔒 **隐私安全 / Privacy Safe** - 敏感数据不会离开您的设备<br>
  Sensitive data never leaves your device
  
- 📱 **响应式设计 / Responsive Design** - 完美适配桌面、平板和手机<br>
  Perfectly adapted for desktop, tablet, and mobile
  
- 🎨 **精美界面 / Beautiful UI** - 现代化的 UI 设计，支持深色模式<br>
  Modern UI design with dark mode support
  
- ⚡ **极速加载 / Lightning Fast** - 基于 Vite 构建，首屏加载飞快<br>
  Built with Vite for lightning-fast first load
  
- 🛠️ **丰富工具 / Rich Tools** - 涵盖开发、编码、格式化等多种实用工具<br>
  Covers various practical tools for development, encoding, and formatting

## 🚀 快速开始 / Quick Start

### 在线使用 / Online Usage
直接访问 / Visit directly：[https://Casey-yuan.github.io/devtools-hub/](https://Casey-yuan.github.io/devtools-hub/)

### 本地开发 / Local Development

```bash
# 克隆项目 / Clone the repository
git clone https://github.com/Casey-yuan/devtools-hub.git
cd devtools-hub

# 安装依赖 / Install dependencies
npm install

# 启动开发服务器 / Start development server
npm run dev

# 构建生产版本 / Build for production
npm run build
```

## 🛠️ 技术栈 / Tech Stack

- **框架 / Framework**: React 18 + TypeScript
- **构建工具 / Build Tool**: Vite 5
- **样式 / Styling**: Tailwind CSS
- **路由 / Routing**: React Router v6
- **状态管理 / State Management**: Zustand
- **图标 / Icons**: Lucide React
- **部署 / Deployment**: GitHub Pages / Gitee Pages
