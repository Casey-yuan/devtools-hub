## 🚀 Quick Start

### Online Usage
Visit directly：[https://Casey-yuan.github.io/devtools-hub/](https://Casey-yuan.github.io/devtools-hub/)

### Local Development

```bash
# Clone the repository
git clone https://github.com/Casey-yuan/devtools-hub.git
cd devtools-hub

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite 5
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **State Management**: Zustand
- **Icons**: Lucide React
- **Deployment**: GitHub Pages / Gitee Pages
