## 🎯 为什么选择 DevTools Hub？

作为开发者，我们经常需要在不同的在线工具之间切换：格式化 JSON、测试正则表达式、编码 URL 等等。**DevTools Hub** 将所有这些必备工具整合到一个统一、美观的界面中。

### 核心优势

- **🎨 一致的体验** —— 所有工具采用相同的 UI 模式，零学习成本
- **⚡ 即开即用** —— 无需注册，无需安装，打开就能用
- **🔐 安全设计** —— 你的数据永远不会离开浏览器
- **📴 离线可用** —— 加载后无需网络也能使用（即将支持 PWA）
- **🆓 永久免费** —— 开源免费，个人和商业用途皆可

## 🚀 快速开始

### 🌐 在线使用（推荐）
**直接访问：** [https://Casey-yuan.github.io/devtools-hub/](https://Casey-yuan.github.io/devtools-hub/)

无需安装，无需注册 —— 立即开始使用！

### 💻 本地开发

```bash
# 1. 克隆仓库
git clone https://github.com/Casey-yuan/devtools-hub.git
cd devtools-hub

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev

# 4. 浏览器打开 http://localhost:5173
```

### 📦 生产构建

```bash
npm run build
```

构建后的文件位于 `dist/` 目录。
